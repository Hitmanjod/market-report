# 📈 Automated Daily Market Report

A fully automated financial market report website that generates and publishes a professional daily market report using Python, APIs, and GitHub Actions.

## Features

✅ **Fully Automated**: Runs every morning without manual intervention  
✅ **No Backend**: Hosted on GitHub Pages (static HTML)  
✅ **Professional Design**: Modern dark theme, card-based layout  
✅ **Real Market Data**: Fetches live prices from Yahoo Finance  
✅ **News Integration**: Top business headlines from NewsAPI  
✅ **AI Summaries**: GPT-powered market analysis and insights  
✅ **Beginner Friendly**: Clean, commented, modular Python code  
✅ **Zero Cost**: Free APIs and free GitHub Pages hosting  

## Tech Stack

- **Frontend**: HTML, CSS
- **Backend Logic**: Python 3
- **Market Data**: Yahoo Finance (yfinance)
- **News**: NewsAPI
- **AI Summaries**: OpenAI GPT
- **Automation**: GitHub Actions
- **Hosting**: GitHub Pages
